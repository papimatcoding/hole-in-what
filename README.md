# Hole in What?

**Hole in What?** is a mobile-first 2D arcade minigolf game built with Phaser + TypeScript.

The game mixes a straightforward **Classic** campaign with **HARD** holes designed around deterministic surprises, learning through failure and replaying for better star results.

## Public beta

The current RC6 beta contains:

- **13 Classic holes** focused on learning mechanics and clean execution;
- **5 HARD holes** built around surprise, adaptation and learned solutions;
- star-based replayability;
- cosmetics and progression;
- a community map editor / playtest / publish loop;
- in-game ratings, comments and bug reporting for beta feedback.

**Play the beta:** https://papimatcoding.github.io/hole-in-what/

## Development

- `dev` — public beta / human-validation build during the current beta phase;
- `main` — stable release branch; beta iteration is promoted here only once accepted for release.

Legacy `troll-golf-*` browser storage keys are intentionally preserved for compatibility with existing beta testers after the repository rename.
